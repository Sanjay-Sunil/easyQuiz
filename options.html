easyQuiz

Snip a question, get the answer next to your cursor.

Allow access to websites

easyQuiz needs this to draw its overlay and take the screenshot.

1. Groq API keys

Free at console.groq.com/keys. Stored only in this browser.

With several keys, each snip uses the next key in turn, and keys that are out of quota are skipped. Groq counts limits per organization, so only keys from different organizations add more quota.

2. Gemini API key

Free at aistudio.google.com/apikey. Used for text-copy answers. Stored only in this browser.

3. Shortcuts

Click a button, then press the combination you want.

Enter

Backup shortcut that works everywhere (even inside embedded frames): open the browser's shortcut settings.

4. Behaviour

How to use

  1. Press the activate shortcut. The cursor becomes a crosshair and the page is locked.
  2. Drag around the question.
  3. Type an optional note and press Enter. If you type nothing, the default prompt is sent automatically.
  4. The answer appears next to your cursor. Longer explanations show in a small panel in the corner.
  5. Retry, start a new snip, or press Exit to use the page again.
