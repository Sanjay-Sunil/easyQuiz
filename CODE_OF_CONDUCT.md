# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and patient, assume good intent, and keep criticism about the work, not the person. Harassment, personal attacks and discriminatory language aren't accepted in issues, pull requests or any other project space.

## Reporting

If someone's behaviour bothers you, report it privately to the maintainer through GitHub
(**Security → Report a vulnerability** also works if you need a private channel), or contact [@Sanjay-Sunil](https://github.com/Sanjay-Sunil).
Every report is reviewed and handled confidentially. Maintainers may remove comments, close threads or block people who break this code.
